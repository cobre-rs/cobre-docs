Cobre's `penalties.json` file supplies the case-wide penalty defaults that the
methodology above prices into the objective. Entity-level and stage-level
overrides layer on top of these defaults through the resolution cascade
described in [§1 Cascade Resolution](#1-cascade-resolution) and
[§3 Penalty Defaults and Overrides](#3-penalty-defaults-and-overrides). This
tab is the field-level configuration reference; the penalty-priority ordering
itself stays in the methodology body above, not here.

### `penalties.json` — Global Penalty Defaults

`penalties.json` is required in every case directory. All four top-level
sections — `bus`, `line`, `hydro`, `non_controllable_source` — are required,
and every scalar cost must be strictly positive.

```json
{
  "$schema": "https://docs.cobre-rs.dev/schemas/penalties.schema.json",
  "bus": {
    "deficit_segments": [
      { "depth_mw": 500.0, "cost": 7000.0 },
      { "depth_mw": null, "cost": 7500.0 }
    ],
    "excess_cost": 100.0
  },
  "line": { "exchange_cost": 2.0 },
  "hydro": {
    "spillage_cost": 0.01,
    "turbined_cost": 0.05,
    "diversion_cost": 0.1,
    "storage_violation_below_cost": 10000.0,
    "filling_target_violation_cost": 6000.0,
    "turbined_violation_below_cost": 500.0,
    "outflow_violation_below_cost": 500.0,
    "outflow_violation_above_cost": 500.0,
    "generation_violation_below_cost": 1000.0,
    "evaporation_violation_cost": 5000.0,
    "water_withdrawal_violation_cost": 1000.0
  },
  "non_controllable_source": { "curtailment_cost": 0.005 }
}
```

#### Bus Section

| Field              | Type   | Description                                                                                                          |
| ------------------ | ------ | --------------------------------------------------------------------------------------------------------------------- |
| `deficit_segments` | array  | Piecewise-linear deficit cost tiers — see [Bus `deficit_segments`](#bus-deficit_segments--two-tier-resolution) below. |
| `excess_cost`      | number | Cost per MWh of excess (surplus) generation.                                                                          |

#### Line Section

| Field           | Type   | Description                                                                            |
| --------------- | ------ | ---------------------------------------------------------------------------------------- |
| `exchange_cost` | number | Cost per MWh of inter-bus exchange flow, applied to every transmission line in both flow directions. |

#### Hydro Section

| Field                                 | Type            | Description                                                                                       |
| -------------------------------------- | --------------- | --------------------------------------------------------------------------------------------------- |
| `spillage_cost`                        | number          | Spillage regularization cost.                                                                       |
| `turbined_cost`                        | number          | Turbined-flow regularization cost, applied to every hydro's turbine column.                         |
| `diversion_cost`                       | number          | Diversion-flow regularization cost.                                                                 |
| `storage_violation_below_cost`         | number          | Storage-below-minimum violation cost.                                                               |
| `filling_target_violation_cost`        | number          | Filling-target violation cost.                                                                      |
| `turbined_violation_below_cost`        | number          | Turbined-flow-below-minimum violation cost.                                                         |
| `outflow_violation_below_cost`         | number          | Total-outflow-below-minimum violation cost.                                                         |
| `outflow_violation_above_cost`         | number          | Total-outflow-above-maximum violation cost.                                                         |
| `generation_violation_below_cost`      | number          | Generation-below-minimum violation cost.                                                            |
| `evaporation_violation_cost`           | number          | Symmetric evaporation-violation cost (both directions, when the two fields below are absent).       |
| `evaporation_violation_pos_cost`       | number or null  | Optional over-evaporation override. Absent = the resolved symmetric `evaporation_violation_cost`.   |

### Bus `deficit_segments` — Two-Tier Resolution

Deficit is priced through a piecewise-linear cost curve rather than a single
flat value. Each segment is a `{ depth_mw, cost }` pair; segments are
cumulative — the first `depth_mw` MW of unmet demand cost the first segment's
`cost`, the next `depth_mw` MW cost the second segment's `cost`, and so on:

```json
"deficit_segments": [
  { "depth_mw": 500.0, "cost": 1000.0 },
  { "depth_mw": null, "cost": 5000.0 }
]
```

| Field      | Type           | Description                                                                                                                        |
| ---------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `depth_mw` | number or null | MW of deficit covered by this segment. The **last segment must be `null`** — unbounded, which guarantees the LP always has a feasible solution regardless of the shortfall size. |
| `cost`     | number         | Cost per MWh of deficit in this segment. Must be positive; segments must be listed in **ascending cost** order.                       |

`deficit_segments` resolves from exactly two sources and does **not** support
stage-level overrides:

1. **Bus-level override** — the `deficit_segments` array on the bus object in
   `system/buses.json`.
2. **Global default** — the `bus.deficit_segments` array in `penalties.json`.

`excess_cost` resolves through a different pair of tiers: there is no
bus-level `excess_cost` override, but the global default may be refined per
stage via `constraints/penalty_overrides_bus.parquet` (see the Inputs &
Outputs tab).

### Line and Non-Controllable-Source Overrides

`exchange_cost` (line) and `curtailment_cost` (non-controllable source) each
fall back to their `penalties.json` global default when no override applies
at a more specific tier:

| Field                                        | Entity-level override                      | Stage-level override                            |
| --------------------------------------------- | -------------------------------------------- | -------------------------------------------------- |
| `line.exchange_cost`                          | `lines[].exchange_cost` in `system/lines.json` | `constraints/penalty_overrides_line.parquet`       |
| `non_controllable_source.curtailment_cost`    | not supported                                | `constraints/penalty_overrides_ncs.parquet`        |

### Resolution Cascade at a Glance

The table below consolidates the tiers each penalty field supports — the
tiers differ per field, so this is a lookup table, not a single uniform rule:

| Penalty field                                | Stage-level override                          | Entity-level override                                                          | Global default                                              |
| ----------------------------------------------- | ------------------------------------------------ | ---------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| `bus.deficit_segments`                          | not supported                                     | `buses[].deficit_segments`                                                          | `penalties.json` → `bus.deficit_segments`                     |
| `bus.excess_cost`                                | `penalty_overrides_bus.parquet`                   | not supported                                                                       | `penalties.json` → `bus.excess_cost`                          |
| `line.exchange_cost`                             | `penalty_overrides_line.parquet`                  | `lines[].exchange_cost`                                                             | `penalties.json` → `line.exchange_cost`                       |
| `hydro.*` (11 cost fields)                       | `penalty_overrides_hydro.parquet` (subset)        | `hydros[].penalties` — see the [Hydro Configure tab](/math/hydro-production-models#implementation-in-cobre) | `penalties.json` → `hydro.*`                                  |
| `non_controllable_source.curtailment_cost`      | `penalty_overrides_ncs.parquet`                   | not supported                                                                       | `penalties.json` → `non_controllable_source.curtailment_cost` |
