Install Cobre and run a study in a few steps.

## Installation

```bash
pip install cobre-python
```

Requires Python 3.12, 3.13, or 3.14.

## Run a Case

```python
import cobre

result = cobre.run.run("path/to/case")
```

The `cobre.run.run()` function loads the case, trains an SDDP policy, optionally
runs simulation, and writes output files. It returns a dictionary with the
following keys:

| Key             | Type              | Description                                     |
| --------------- | ----------------- | ------------------------------------------------ |
| `converged`     | `bool`            | Whether training converged                      |
| `iterations`    | `int`             | Number of training iterations completed         |
| `lower_bound`   | `float`           | Final lower bound                               |
| `upper_bound`   | `float` or `None` | Final upper bound (None if no simulation)       |
| `gap_percent`   | `float` or `None` | Optimality gap percentage (None if unavailable)  |
| `total_time_ms` | `int`             | Total wall-clock time in milliseconds           |
| `output_dir`    | `str`             | Path to the output directory                    |
| `simulation`    | `dict` or `None`  | Simulation summary (if enabled)                 |
| `stochastic`    | `dict` or `None`  | Stochastic preprocessing summary                |
| `hydro_models`  | `dict` or `None`  | Hydro model summary                             |
| `provenance`    | `ProvenanceReport` or `None` | Build version and environment metadata (a `ProvenanceReport` typed dict, or `None` when provenance was not captured) |

```python
print(f"Converged: {result['converged']}")
print(f"Iterations: {result['iterations']}")
print(f"Lower bound: {result['lower_bound']:.2f}")
if result['gap_percent'] is not None:
    print(f"Gap: {result['gap_percent']:.2f}%")
print(f"Output dir: {result['output_dir']}")
```

## Optional Parameters

```python
result = cobre.run.run(
    "path/to/case",
    output_dir="path/to/output",   # default: case_dir/output
    threads=4,                      # default: None → 1 worker
    config_overrides={"simulation": {"enabled": False}},  # default: None
)
```

- **`output_dir`**: where to write results (default: `case_dir/output`).
- **`threads`**: worker count for the internal pool. Default `None` ⇒ **1 worker**. `0` is **rejected** (`ValueError: threads must be >= 1 when given`); a value `≥ 1` sets the worker count.
- **`config_overrides`**: a dict merged into `config.json`. Both nested `{"simulation": {"enabled": False}}` and flat dotted `{"training.tree_seed": 7}` shapes are deep-merged into the configuration.

## Validate a Case

Before running a study, validate the case directory to check for errors:

```python
import cobre.io

report = cobre.io.validate("path/to/case")
# Returns: {"valid": bool, "errors": [...], "warnings": [...]}

if not report["valid"]:
    for e in report["errors"]:
        print(f"{e['kind']}: {e['message']}")
```

`Study(...).validate()` returns the same-shaped dict.

## Error Handling

Cobre defines a typed exception hierarchy under `cobre.errors`. All exceptions inherit from `CobreError` (the common base) and also from the matching builtin (`ValueError`, `OSError`, or `RuntimeError`), so existing `except OSError` handlers keep catching while new code can catch the typed class.

| Exception                  | Inherits                        | Description                                                                                         |
| -------------------------- | ------------------------------- | --------------------------------------------------------------------------------------------------- |
| `CobreError`               | `Exception`                     | Base class for every Cobre exception                                                                |
| `ValidationError`          | `CobreError`, `ValueError`      | Case data or configuration failed validation. Setup-phase validation messages start `setup validation error: ` |
| `PolicyIncompatibleError`  | `CobreError`, `ValueError`      | A policy load refused the checkpoint: another cobre version wrote it, or its stored bases, state or graph do not fit the study. Messages start `policy validation error: ` |
| `CaseIoError`              | `CobreError`, `OSError`         | A filesystem read or write failure while loading or writing a case                                  |
| `OutputError`              | `CobreError`, `OSError`         | An output serialization, schema, or manifest failure while writing results                          |
| `SolverError`              | `CobreError`, `RuntimeError`    | A training or solver failure. For an infeasible subproblem, the `.stage`, `.iteration`, and `.scenario` attributes are the integer coordinates; otherwise they are `None`. Also raised when a warm-start, resume, or simulation-only load cannot read its checkpoint, and when a boundary load refuses a checkpoint for a reason other than a cobre-version mismatch (messages start `boundary cut error: `) |
| `SimulationError`          | `CobreError`, `RuntimeError`    | A simulation-phase failure                                                                          |
| `InternalError`            | `CobreError`, `RuntimeError`    | An internal software or environment fault                                                           |

See [Error Codes](/reference/error-codes/) for the full catalogue.
[Policy-load errors](/reference/error-codes/#policy-load-errors) states which load path raises which class.

## Read Output with Polars

Cobre writes results as Parquet files, which can be loaded directly with
Polars or any Arrow-compatible library:

```python
import polars as pl

# Convergence trajectory
convergence = pl.read_parquet("output/training/convergence.parquet")
print(convergence.head())

# Simulation costs (if simulation was enabled) — Hive-partitioned
costs = pl.read_parquet("output/simulation/costs/")
print(costs.describe())
```

## Arrow Zero-Copy Loading

For larger datasets, use the built-in Arrow loaders that avoid serialization
overhead:

```python
# Returns a pyarrow.Table (zero-copy)
convergence_table = cobre.results.load_convergence_arrow("output/")
simulation_tables = cobre.results.load_simulation_arrow("output/")

# Convert to Polars without copying
import polars as pl
df = pl.from_arrow(convergence_table)
```
