# Spec Gap Inventory

This document tracks specification gaps — areas where the spec corpus does not yet fully describe implemented behavior or where known divergences between spec and code exist.

> **Status**: Content pending. This file exists to resolve cross-reference links from the [Cross-Reference Index](../cross-reference-index.md) and related specs.

Entries will be organized by domain (math, data-model, architecture, HPC, interfaces) and will record the gap description, the affected spec file, the corresponding code location, and the priority for resolution.
